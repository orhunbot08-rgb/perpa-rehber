# Perpa Rehber

Perpa Ticaret Merkezi'ndeki firmaların ürünleri ve dükkan yerleri: ürün arama + kuş bakışı kat planı.
Telefonda açıp "Ana ekrana ekle" ile uygulama gibi kurulabilir.

Perpa Ticaret Merkezi'nin resmi uygulaması değildir. Firma bilgileri Perpa rehberi, perpahaber.com ve firmaların kendi web sitelerinden derlenmiştir.
